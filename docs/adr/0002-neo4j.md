# 0002. Neo4j as the knowledge store

- Status: accepted
- Date: 2026-11-27

## Context

Diagnosis follows relationships (symptom to issue to possible cause to the check that tests it), so a graph store fits. ArangoDB and Neo4j were compared. Both can hold the graph, vectors and text search in one store.

## Decision

Use Neo4j: AuraDB Free for the hosted demo, a Neo4j container for local development and CI.

- AuraDB Free has no time limit and needs no credit card, so the live demo stays free.
- ArangoDB's hosted trial lasts 14 days, and its Community Edition is limited to non-commercial use.
- Neo4j has the larger GraphRAG and LangChain ecosystem.

## Consequences

- Free-tier size limits apply; 10 to 15 canonical issues are far below them.
- Graph retrieval must beat plain hybrid retrieval in the eval (see the eval design); if it does not, the README says so.
